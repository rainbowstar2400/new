# Product Brief v0.3

- 作成日: 2026-02-15
- プロダクト名（仮）: 自分専用秘書PWA
- 方針: Online MVP v0.3（モバイルUI再編）
- 参照: `ProductBrief_v0.2.md`, `ProductBrief_v0.1.md`

## 1. 背景（v0.2 -> v0.3）

- `v0.2` でオンラインMVPの基盤（API/DB/Push/会話フロー）は確立した。
- 一方で、UI導線と分類境界の体験品質に改善余地が残った。
- `v0.3` では `v0.2` を凍結し、未実装・未完了の改善項目を再編して実装する。

## 2. v0.3の目的

- モバイル操作を前提に、下部固定タブUIへ全面刷新する。
- タスク/メモ/メモ分類の境界判定を改善し、誤保存を減らす。
- 一覧画面の視認性（`!期日設定` 含む）を改善する。

## 3. 対象ユーザー

- 初期: 作成者本人
- 将来: 同様の課題を持つ個人ユーザー

## 4. 提供価値（v0.3）

- `チャット / メモ・タスク / 設定` の3タブで操作を明確化する。
- `メモ・タスク` で `すべて / メモのみ / タスクのみ` の切替が可能になる。
- 起動時に前回タブと前回フィルタを復元し、操作継続性を上げる。
- 曖昧入力時は確認を徹底し、`メモ` 選択後はカテゴリ確定前に保存しない。

## 5. v0.3スコープ

- モバイル下部タブUIの全面刷新（構造・見た目）
- `?taskId=` 深リンク時の一覧タブ自動遷移 + 強調表示
- 分類境界強化（`〜たい`, 単語タスク, 曖昧確認）
- 一覧カードのメタ情報整理と `!期日設定` 視認性強化
- テスト更新（単体/結合/E2E）
- `Documents/*_v0.3.md` と `Issues/*_v0.3.md` の同期

## 6. 非目的（v0.3でやらない）

- 公開API追加
- DBスキーマ変更
- メール認証・複数アカウント
- 外部サービス双方向同期

## 7. 成功指標（v0.3）

- モバイル主要導線（3タブ遷移・フィルタ切替）のE2E通過率 100%
- `task_or_memo -> memo_category` 強制フローの回帰不具合 0件
- `!期日設定` 対象の視認見落とし報告の低減
- 既存KPI（5秒以内保存率、分類修正率）の悪化なし

## 8. リリース判定

- `Backlog_v0.3.md` の `P1-01`, `P2-01`, `P2-02` を完了
- `PRD_v0.3.md` の受け入れ基準を満たす
- `pnpm test` と `pnpm --filter @new/web test:e2e` が通過
- `v0.2` 文書未変更を維持し、`v0.3` 文書6点が同期している
