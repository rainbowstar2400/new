# PRD v0.3

- 作成日: 2026-02-15
- 対象: Online MVP v0.3（UI再編 + 分類品質改善）
- 参照: `ProductBrief_v0.3.md`, `UseCases_v0.3.md`, `PRD_v0.2.md`, `PRD_v0.1.md`

## 1. 概要

`v0.3` は `v0.2` を凍結したまま、未完了項目を「モバイル下部タブUI」「分類境界」「一覧調整」に再編して実装する版である。

## 2. スコープ

- 下部固定タブUI（`チャット / メモ・タスク / 設定`）
- `メモ・タスク` タブの3状態フィルタ（`all/memo/task`）
- タブ状態とフィルタ状態のローカル復元
- `?taskId=` 深リンクで `メモ・タスク` 自動遷移 + 対象強調
- 分類境界改善（`〜たい`, 単語タスク, 曖昧入力確認）
- `task_or_memo -> memo_category` 強制フロー維持
- 一覧視認性改善（`!期日設定` バッジ、メタ情報優先度）

## 3. 非スコープ

- APIエンドポイント追加
- DBスキーマ変更
- 認証方式変更（メール認証等）
- 通知配信基盤の新規追加変更

## 4. 機能要件（FR）

| ID | 要件 |
| --- | --- |
| FR-26 | UIは `チャット / メモ・タスク / 設定` の3タブを下部固定で提供すること |
| FR-27 | タブバーはモバイル優先設計で、`env(safe-area-inset-bottom)` に対応すること |
| FR-28 | `メモ・タスク` タブで `all/memo/task` フィルタを切替できること |
| FR-29 | 起動時に `active_tab_v03` を復元し、未保存時は `chat` を初期表示すること |
| FR-30 | 起動時に `items_filter_v03` を復元し、未保存時は `all` とすること |
| FR-31 | `?taskId=` を検出した場合、`メモ・タスク` タブへ遷移し対象カードを強調すること |
| FR-32 | チャットタブは既存会話制御（`inputMode/confirmationType/negativeChoice`）を維持すること |
| FR-33 | `〜たい` 系入力を `memo(want)` 側へ優先分類できること |
| FR-34 | 単語タスク（例: 洗濯/掃除/買い物）を `task` 側へ優先分類できること |
| FR-35 | 曖昧入力は保存前に `task_or_memo` 確認を返すこと |
| FR-36 | `task_or_memo` で `メモ` 選択時、`memo_category` 確定前の保存を禁止すること |
| FR-37 | `memo_category` 未確定のまま `misc` 自動確定保存しないこと |
| FR-38 | 一覧で `pending_due` を `!期日設定` として明確に強調表示すること |
| FR-39 | 一覧カードの表示優先度は `種別 -> メモ分類 -> 期日状態` を基本とすること |
| FR-40 | 項目0件時に空状態UIを表示すること |

## 5. 公開I/Fとデータ

### 5.1 公開API

- 変更なし（`/v1/chat/messages` など既存を維持）

### 5.2 DBスキーマ

- 変更なし

### 5.3 フロント内部I/F

- `TabKey = "chat" | "items" | "settings"`
- `ItemFilter = "all" | "memo" | "task"`
- `localStorage` key:
  - `active_tab_v03`
  - `items_filter_v03`
- 既存継続:
  - `response_tone`
  - `default_due_time`

## 6. UX要件

- 既存 `.layout/.panel` を流用せず、新規クラス体系で画面再構築する。
- モバイルを基準に、デスクトップでは中央カラムで拡張表示する。
- タブ切替に軽量アニメーション（フェード/スライド）を付与する。
- 視認性向上のため、選択中タブと `!期日設定` を強く識別できる配色を採用する。

## 7. 非機能要件

- 既存会話フローの回帰を起こさないこと
- 主要操作を片手操作で完了できるレイアウトであること
- `pnpm test` と `pnpm --filter @new/web test:e2e` を通過すること

## 8. 受け入れ基準

- AC-01: 下部タブで3画面遷移できる
- AC-02: `メモ・タスク` で `all/memo/task` フィルタが機能する
- AC-03: 再起動後に前回タブ・前回フィルタが復元される
- AC-04: `?taskId=` で一覧タブ遷移 + 対象強調が機能する
- AC-05: `〜たい` が `memo(want)` に分類される
- AC-06: `洗濯/掃除/買い物` が `task` に分類される

- AC-08: `!期日設定` バッジが高視認で表示される
- AC-09: 既存 `inputMode` 制御の回帰がない
