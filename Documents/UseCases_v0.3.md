## 3. 会話フロー（v0.3）

### 3.1 登録フロー

1. ユーザー入力を分類する。
2. 明確なら即保存または期日確認へ進む。
3. 曖昧なら `task_or_memo` を返す。
4. `メモ` 選択時は必ず `memo_category` を返す。
5. カテゴリ確定後に保存する。

### 3.2 UIフロー

1. 画面下部の固定タブから画面遷移する。
2. `メモ・タスク` タブでフィルタ切替する。
3. フィルタ状態を次回起動時に復元する。
4. `?taskId=` で対象項目を優先表示する。

## 4. 表示ポリシー

- 一覧カードは `種別 -> メモ分類 -> 期日状態` の順で情報を配置する。
- `pending_due` は `!期日設定` として強調し、`no_due` と明確に区別する。
- 0件時は空状態画面を表示し、次操作を案内する。

## 5. v0.1 / v0.2 回帰観点

- `明日18時に洗濯` のタイトル正規化（`洗濯`）
- `〜たい` の `memo(want)` 維持
- `task_or_memo -> memo_category` 強制
- `inputMode` 制御（`choice_only`, `choice_then_text_on_negative`）維持
